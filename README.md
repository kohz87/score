# Score

A multi-agent workspace for [Hermes Agent](https://github.com/NousResearch/hermes-agent): one screen for the
whole team's live work, hand-offs between agents, and one-click approvals.

Status: **Phase 0** (plan + empty scaffold). No features yet.
