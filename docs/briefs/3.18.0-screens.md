# 3.18.0 — Screens in the top bar (owner, 2026-11-02: "put screen navigation on the top … easier to access bot screen")

Approved mock-up ("yes, build it"): `docs/design/bold/mockups/15-screens.dc.html` (desktop) and `15-screens-phone.dc.html`,
canvas https://claude.ai/artifact/9dWyfTob55Y3TZW3d2xDdY. Take look and copy from them and the shell's existing CSS
tokens; rebuild in React, never paste the mock-up's HTML. Web only: no server or contract change.

## Build
- **Route** `/b/screens` (`BoldScreensPage` in `apps/web/src/bold/`), and **Screens** in the top bar after Tasks
  (`BoldShell.tsx`: desktop nav and the phone top bar's pills, as Tasks was added in 3.16.0). Each card links to the
  existing screen page (`boldAgentScreenLink` in `bold-links.ts`).
- **Data** (existing endpoints only): `useWatchOverview()` (`routes/watch/watch-queries.ts`: per agent `thumbnail`,
  `status`, `live`, `surface`) and, per agent, the Bot Desktop status `botScreenQuery(agentId)` (polled every 5 s while the
  page is visible, not faster: several agents).
- **Card** (desktop grid, `repeat(auto-fill, minmax(300px, 1fr))`): a 16:10 miniature, then AgentGlyph + name + what it
  is doing (`status`), then **Open screen** and, only when its Bot Desktop is `running` and nobody holds it, **Take over…**.
  Miniature, in this order: a running Bot Desktop → its frame (`botScreenFrameUrl(agentId, frameSeq)`, as the Live screen
  does, refreshed with the 5-s status); bot-screen state `human` → no picture, the line "Someone has taken over this
  desktop. Score hides it while they work."; else the overview `thumbnail` if any; else a small drawing of the `surface`
  (terminal / editor / browser) like the mock-up; else "Nothing on screen".
- **Badge** on the miniature: "Live desktop" (with the pulsing dot, reduced-motion respected) for a running desktop;
  "Someone has control" (red) for `human`; "Working · terminal|editor|browser" when `live`; "Idle" otherwise. The
  "Someone has control" badge carries `data-protected` and joins the protected list (`themes/protected-surfaces.ts`).
- **Take over…** links to the screen page with `?take=1`; the screen page's Live screen opens its confirm card on load when
  that parameter is present (and the screen can be taken), then drops the parameter from the URL. Small change in
  `BoldLiveScreen.tsx` only.
- **Phone** (≤ 600px): rows (miniature 128px wide, name, badge text, doing), as the mock-up; whole row is the link.
- Empty state: "No agents yet." Errors: the overview failing shows a plain line, cards still render from the agent list.
