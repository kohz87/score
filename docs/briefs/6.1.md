## Done when

   Markdown preview may be plain text for now. Unavailable states show the reason (remote backend, unset folder).
5. Tests: path-safety unit tests (symlinked parent, symlink race on rename, `..`, NUL, absolute, blocked patterns incl.
   nested `.env.local`, `.git/` internals, `~/.hermes` resolution), size limits, etag conflict, atomic write, upload,
   routes with `inject()`, web component tests, e2e on the fake adapter (browse, edit + save, conflict, create, delete),
   visual baseline for the new tab checked by eye.
