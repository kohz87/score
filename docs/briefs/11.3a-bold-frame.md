its own route prefix and a per-browser switch in `user-view.ts`. The bold shell works the same way.

## What to build
1. **Per-device switch** `apps/web/src/bold/bold-ui.ts`: `readUi(): 'bold' | 'classic'` and `saveUi()` (localStorage
   key `score.ui`, every access in try/catch as `user-view.ts` does). Opening any URL with `?ui=bold` saves `bold`;
   `?ui=classic` clears it. Never sent to the server.
2. **Routes** in `App.tsx`: a `/b` branch with `BoldShell` (like `/u`): `/b` (Room), `/b/team`, `/b/settings`.
   The index route redirects to `/b` when `readUi() === 'bold'`, otherwise exactly as today. Nothing else in the
   classic routes changes.
3. **`BoldShell`** (`apps/web/src/bold/BoldShell.tsx` + `bold.css`), as `vTop()` and `tabbar()` draw it: the `score`
   wordmark (goes to the room), nav Room · Team, the **team dock** (one ring per agent from the existing agents
   query: a `conic-gradient` arc in the agent's colour showing its progress, the glyph inside without eyes, the
   `needs` outline when it needs you, the "Rings show progress" label; clicking does nothing yet, its aria-label says
   "One to one with <id>, <state>"), the Search button with the `⌘K` key hint (⌘K / Ctrl+K opens the existing
   `CommandPalette` for now), the gear for Settings and the "Y" avatar. Below it `.main`: the room column on the left
   (room title button "Team room" with the chevron, no menu yet) and the **side panel** (`.side`) on the right with its
   head and dropdown (Work · Library · Thread · One to one; choosing one only changes the placeholder). Team and
   Settings are placeholder pages ("Team comes in 11.8", "Settings come in 11.9"). At ≤ 860px: the top bar keeps only
   the wordmark and avatar, the side panel is hidden, and the fixed bottom tab bar Room · Team · Search · Settings with
   the prototype's icons appears. The room fills the window (`body.fit`): the page never scrolls.
4. **Tokens** `apps/web/src/bold/tokens.css`: the prototype's `:root` properties, scoped under `[data-ui='bold']`
   (set on the shell's root element so nothing leaks into the classic shell), and its light set under
   `[data-ui='bold'][data-look='light']`, chosen by `prefers-color-scheme: light` for now (Settings › Look comes later).
   Agent colours come from Score's agent data/AgentGlyph as today, with the README's light name tints on dark. Fonts
   from the existing `@fontsource` imports (never Google Fonts). No raw colours in `bold.css` outside `tokens.css`.
5. **Motion**: the prototype's `livedot`/`pulse` animations where the frame uses them; under
   `prefers-reduced-motion: reduce` every animation and transition in the frame stops.
