# 8.1 CLI quota meters (decisions 82; PLAN 8.1)

Team › coding agent shows each CLI's own quota as meters instead of text. No extra CLI calls.
- **Antigravity:** today's `/usage` answer (`GET /api/coding-agents/runtimes/antigravity/usage` → `CodingUsage`), rendered as
  meters per model group: 5-hour and weekly "% left", reset times in the browser's timezone, "?" when unknown (the raw text
  the owner pasted had `?%`).
- **Claude Code:** every turn sends `rate_limit_event` with `rate_limit_info.unifiedWindows.five_hour|seven_day
  {utilization, resetsAt}` (captured from 2.1.301; see `/home/raven/.claude/jobs/999c85f0/tmp/clicheck/claude-code.v2.stdout.jsonl`).
  The driver keeps it ignorable for verdicts, but the latest one per agent is stored (zod-validated, only these numeric
  fields) with the time it was seen; shown as "as of <time>".
- **Codex:** after a Codex turn Score started ends, read **only that run's** session log — `$CODEX_HOME/sessions/<y>/<m>/<d>/
  rollout-*-<threadId>.jsonl` (thread id from `thread.started`; CODEX_HOME from the CLI env, default `~/.codex`) — tail
  only (bounded, e.g. last 256 KiB), take the last `rate_limits` object (`primary/secondary {used_percent, window_minutes,
  resets_at}`), zod-validated; never read any other Codex file, never store anything but those numbers. Missing or
  unrecognised ⇒ "unknown". `lstat` + `O_NOFOLLOW`, regular file, owned by the user.
- One contract shape for all three (contract doc first): `CodingQuota { runtime; seenAt; windows: { name: '5 hours' |
  'week' | <group>; usedPercent: number | null; resetsAt: string | null }[]; source: 'usage' | 'turn' | 'log' }`.
  Storage: migration 0069 (`coding_quota`, one row per agent/runtime, latest only).
- Web: a small meter component (bar + "% left" + "resets 1:46 pm"), on the coding agent page and as a compact line in the
  agent picker; colours from tokens; reads well in dark mode; plain words (docs/WRITING.md).
Tests: driver/event parsing from the captured records; Codex log reader with a fixture (symlink refused, other files
never opened, missing ⇒ unknown); route + web component; e2e in fake mode.
