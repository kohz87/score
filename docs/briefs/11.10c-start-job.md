## Build
`BoldStartJob` dialog on `/b`, opened by `?start=job` (the link `apps/web/src/bold/bold-links.ts` from 11.10f will
use; read `?start` yourself) and by the room's "Start a job" buttons (render the opener from `BoldShell.tsx`, a few
lines; the room's own buttons come with 11.4). Recipe "lead decides" → a job in the team room with an orchestration;
a saved recipe → a workflow run; none → a plain job. When: now / once at / on a schedule (a routine; existing routines
show as scheduled jobs in a "Scheduled" list in the dialog) / when an app calls (a trigger, with the secret shown once
in a protected card). Budgets and deadline map onto the fields above; the checklist (D2) blocks Start until every
item passes. "Save as a recipe" saves the step list through the workflows API. Phone: full-screen sheet.
