## Task (from docs/PLAN.md)
**3.13 Remote access mode** (owner: "allow private network and plain LAN address").

**Binding design: the Codex adversarial review `docs/reviews/2026-10-08-3.13-remote-design-codex.md` (read it fully; its
corrected design list is the plan) plus these lead decisions:**
1. **Modes**: (a) `local` (default, today's behaviour; **non-loopback `SCORE_HOST` is refused** unless remote mode is on);
   (b) `remote` with TLS (`SCORE_TLS_CERT`/`SCORE_TLS_KEY`, e.g. a Tailscale cert) — the recommended path; (c) `remote` over
   plain HTTP **only** with `SCORE_REMOTE_INSECURE_HTTP=accept` (owner allowed plain LAN): startup logs a loud warning, and the
   app shows a permanent banner "Plain HTTP: anyone on this network could read and control Score" with a link to the TLS
   setup. Private-network (Tailscale/WireGuard) use is plain HTTP over an encrypted tunnel and uses (b) or (c) with the
   tunnel interface address. Wildcard binds (`0.0.0.0`, `::`) need `SCORE_REMOTE_ANY=1`.
2. **Two listeners**: the browser listener on the configured address (remote) and a **loopback-only HTTP listener for the
   bridge plugin** (`/bridge/*` routes registered only there). Startup fails clearly if either can't bind.
3. **Deny by default** in remote mode: an onRequest auth hook before any handler; exact public method/path list (pairing
   redemption, boolean session status, minimal health, built static assets); everything else (all /api incl. previews,
   HEAD, the SSE stream, media) needs a paired session. `Cache-Control: no-store` on private responses. Serve the built
   web app from Fastify (`pnpm build` output); Vite stays loopback-only.
4. **Host/Origin**: configured public authorities and origins (`SCORE_PUBLIC_ORIGINS`, scheme+host+port) independent of the
   bind address; reject other Host headers (DNS rebinding) and missing/null/foreign Origins on mutations; no proxy trust.
5. **Pairing**: in remote mode the pair page shows what pairing grants and needs a "Pair this browser" click; bounded
   attempts (global + per peer, backoff, no permanent lockout); console command/endpoint (loopback only) to mint a new
   pairing link without restarting. Sessions: idle and absolute expiry (e.g. 7 d idle, 30 d absolute; heartbeats don't
   renew), cookies HttpOnly + SameSite=Strict (+ Secure with TLS).
6. **Browsers in Settings**: list paired browsers (management id ≠ credential, label, last seen, address) and revoke;
   revocation and expiry close that session's open SSE streams immediately; the web app clears caches on logout.
7. Remote mode never touches Hermes (no key rotation, plugin installs, gateway restarts).
8. Contract first: API-CONTRACT (sessions/browsers endpoints, public list), `packages/contract`, ARCHITECTURE D7 note
   (the lead authorises editing D7 for this), SETUP (how to enable each mode, Tailscale cert example).
