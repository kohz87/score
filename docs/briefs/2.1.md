## Design (from the lead)

- **Migration `apps/server/migrations/0008_rooms.sql`** (this number is reserved for you): `rooms` (id, name UNIQUE,
  kind room|direct, lead_agent_id, members JSON, created_at, updated_at, version), `room_reads` (room_id PK,
  last_read_message_created_at, last_read_message_id), `messages` (id, room_id, author_kind you|agent,
  author_agent_id, to JSON, parts JSON, refs JSON, streaming INTEGER, created_at, updated_at, version; index
  `(room_id, created_at, id)`). STRICT tables.
- **Endpoints** (contract §5): `GET /api/rooms` (`rooms` = kind room; `directs` = one direct room per agent from
  `port.listAgents()`, created lazily and idempotently, named after the agent), `POST /api/rooms`, `PATCH
/api/rooms/:roomId`, `GET /api/rooms/:roomId` (`filesInPlay: []`, `learned: []` for now; task 2.8 fills them),
  `GET /api/rooms/:roomId/messages?before=&limit=` (newest first, opaque cursor on `(created_at, id)`, limit ≤ 100),
  `POST /api/rooms/:roomId/messages`: validate the body, store a `{kind:'you'}` message with `parts: [{kind:'text',
text}]`, `to` = the request's `to` (deduped, must be known agents; 400 otherwise), emit `message.created`;
  respond `{ message, routedTo: [], command: null }`. **Parsing @mentions and slash commands and routing are task 2.3**
  (a pure parser arrives in 2.2) — leave a single clearly named seam (e.g. `routeMessage()` returning `{routedTo: [],
command: null}`). Mutating routes use the human guard and `Idempotency-Key` receipts.
- **Stream**: `room.upserted` (new in the contract) on create/update and when `unread`/`activeAgents` change;
  `message.created` for stored messages. `unread` = agent messages after the room's read marker; reading the newest page
  (`GET …/messages` without `before`) moves the marker. `activeAgents` = agents that authored a message in the last 10
  minutes or are typing (keep it simple: authored).
- **Fake mode**: the fake scenario's `message.created`/`message.delta`/`message.completed` steps must persist into
  `messages` (delta appends to the last text part; completed clears `streaming`) and its room into `rooms`, so the
  endpoints return the scenario's conversation. Check `apps/server/src/hermes/fake/{scenario,fake-port}.ts`.
- Text limits: `text` ≤ 16 KB; room name `^#?[a-z0-9][a-z0-9-]{0,63}$` (store with leading `#`).
