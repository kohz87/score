## Build (apps/web only, bold shell)
1. **Start a job** (`apps/web/src/bold/BoldStartJob.tsx`, lead mode only), next to the Advisor and check sections: an optional,
   folded **Helpers** section:
   - pick 1–4 helper agents (any team agent except the lead; same picker style as the agents list);
   - "At once" (1–6, default 3), "Helper steps" (1–60, default 20);
   - **Scan the project first** toggle + folder (absolute path; prefill with the check's folder when one is set, else the first
     selected coding agent's workspace, like the check folder does); show the folder on the folded summary when scan is on;
   - **When the helpers split on a vote:** "The lead decides" (default) / "Ask me";
   - help: "Cheap agents for narrow, read-only work: the lead hands them searches, greps and audits, and asks them to vote on
     small choices. A clear majority (70% or more) is taken; a split goes to the lead or to you. They run with their own tools,
     so choose agents set up for reading."
   - Send `helpers` only when at least one helper is picked. Include helpers in the preflight query's `allowedAgents` and their
     coding policies in `codingPolicies` / `acknowledgeCodingReach` exactly as the 3.14 advisor change did (see how
     `advisorAgentId` is handled now and generalise it). Don't add helpers to `allowedAgents` in the body. Drop the lead from
     the helpers if it is chosen as lead.
2. **The job's view** (`bold/BoldRuns.tsx`, `routes/orchestrations/RoomRunPanel.tsx`, next to `AdvisorCard` and `CheckCard`): a
   **Helpers** card when `detail.helpers` is non-null: the helpers (AgentGlyph), "N of M helper steps", "up to K at once",
   the scan folder when scan is on; and **Votes**: each vote's question, each option with its count and a bar of its share,
   the status pill (voting / sharp / split / no usable answers), the chosen option highlighted when sharp, "asked you" when
   `inquiryId` is set (the inquiry itself already shows on Needs you).
   - Steps with `role === 'vote'` must not appear in step lists/graphs/threads (extend `leadSteps()` in
     `routes/orchestrations/orch-model.ts` to drop `'vote'` too). Steps with `role === 'helper'` are the lead's work and DO stay
     visible, marked with a small pill of their `helperRole` (search / grep / audit / scan: stack / scan: scripts / scan: risks).
3. Styles: reuse the Advisor/Check card look; bold tokens; phone width without horizontal scroll (vote bars shrink).
