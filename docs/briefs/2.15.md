## Design (from the lead) — this is the ONE place Score writes inside a Hermes profile (ARCHITECTURE D2.6)
- **Server** (contract §8): `GET /api/agents/:agentId/files/:file` → `{ content, etag }`; `POST
  …/files/:file/preview {content}` → `{ diff }` (unified diff, computed in-process; no dependency: write a small
  Myers/LCS line diff); **H** `PUT …/files/:file {content, etag}` → `{ etag }`, 409 `conflict` with `{ etag,
  diff }` (current vs submitted) on mismatch. `file` ∈ `SOUL.md|AGENTS.md` exactly (zod enum; 404 otherwise).
- **Writer** (`apps/server/src/hermes/live/profile-files.ts`): resolve `<profile home>` through the existing profiles
  reader/paths; refuse symlinks for the directory and the file (`lstat`), require the final path to be exactly
  `<home>/SOUL.md` or `<home>/AGENTS.md` after `realpath` of the directory; etag = sha256 hex of the current bytes (missing
  file → etag of the empty string; create allowed only for AGENTS.md? no: both may be created); write to a temp file in
  the same directory (`O_CREAT|O_EXCL`, mode 0644 or the existing file's mode), fsync, rename over, fsync the directory;
  compare-and-swap: re-read and re-hash immediately before the rename and 409 if it changed; per-file in-process lock.
  Content ≤ 256 KB, UTF-8, no NUL. Never touch `.env`, `auth.json`, `config.yaml` or anything else (test with an fs spy
  like 2.13's). Emit `agent.updated` (the excerpt changes) through ingest.
- **Fake**: in-memory files per agent with the same etag semantics.
- **UI**: on the Team page, the **Personality** tab (SOUL.md) and the rules file entry (AGENTS.md) open an editor: textarea,
  "Preview changes" shows the diff, "Save" sends the etag; on 409 show the server's diff and offer "Reload theirs" /
  "Overwrite with mine" (re-PUT with the new etag). Files: `apps/web/src/routes/team/` editor components.
