## Build
1. **Chat list** (left column, desktop): every room a person talks in, from the existing queries — the team room(s)
   (`GET /api/team-room`, `GET /api/team-rooms`), other rooms people use (`GET /api/rooms` minus hidden run rooms) and
   the directs (one per agent). Two groups, **Groups** and **Direct**, newest activity first; each row: a tile (initial
   for groups, AgentGlyph for directs), name, a short second line from data that exists today (the room's newest job
   title or state, or the agent's status — no new server field), unread count, and a light **needs you** badge
   (`data-protected`) when something in that room needs the person (reuse how the shell counts needs-you today).
   Search box filters by name. **+** opens the existing "new team room" flow (members and lead). A **‹** button folds
   the list into a narrow rail of tiles (and **›** unfolds it); remember the choice per device (localStorage, guarded).
2. **The chat** (centre): the selected room's existing view — the team room's stream and composer for groups, the
   existing one-to-one view for directs — reached at their existing addresses (`/b`, `/b?...`, the direct's address).
   Selecting a chat in the list navigates there. A **chat header**: name, "Owner <lead>" (the room's lead, or "no owner
   yet"), member count, the room's workspace name when set (3.20.0 `Room.workspaceId` + `GET /api/workspaces`), and a
   **Chat info** button.
3. **Right panel**: the existing side panel gains an **Info** tab beside its current modes: members (glyph, name, "owner"
   for the lead), the workspace, and the room's jobs listed as **Topics** (state dot + title, linking to each job as
   today). Chat info toggles the panel; it can be closed for full width.
4. **Top bar**: "Room" becomes **Chats** (the same destination). Another task in parallel renames "Team" to "Agents"
   and adds "Knowledge" in another worktree: change only the Room label here; the lead merges both.
5. **Phone** (≤ 600px): the chat list is the first screen (`/b` on a phone shows the list), tapping a chat opens it full
   screen with a Back button to the list; the existing bottom nav stays.
