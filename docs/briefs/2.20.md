**2.20 Settings: advanced config**: config search index + diff preview UI. Done when search finds keys by name and comment;

## Design (from the lead)

- **Index**: keys, current values and comments for the profile's `config.yaml` (default profile; a profile selector is a
  nice-to-have). Build the comment/description index from the tested Hermes version's defaults
  (`../reference/hermes-agent/hermes_cli/config_defaults.py`, committed as a generated, neutral JSON fixture under
  `apps/server/src/hermes/live/` with a script to regenerate it) and current values from `hermes config get --json <key>`
  (Hermes masks secrets). **Exclude** every secret-bearing or env-backed key (Hermes's `is_env_setting_key`,
  `_is_secret_config_key` logic: anything with key/token/secret/password/credential in its name, `providers.*.api_key*`,
  `*.env`, `*.headers`) from both search results and writes.
- **Endpoints** (contract §10): `GET /api/settings/config?q=` (name + comment search, ≤ 50 results), `POST
/api/settings/config/preview {changes}` → `{ diff, file, hash }` (a unified diff of the affected keys' YAML rendering;
  `hash` = sha256 of the diff + current values), **H** `POST /api/settings/config/apply {changes, expectedDiffHash}` →
  recompute the preview; 409 if the hash differs (config changed meanwhile); else `hermes config set <key> <value>` per change
  (values JSON-encoded where needed), re-read and verify; `restartRequired` from a small known list (gateway/platform keys).
  Never write excluded keys (400). Update the contract schemas (`packages/contract`) for these shapes.
- **UI**: the Settings "Advanced" section (search box from `docs/design/settings.png`), results with key, value, file and
  comment, inline edit, a pending-changes tray with "Preview" (diff) and "Apply" (sends the hash).
- **Fake**: an in-memory config with a few neutral keys.

## Done when

Search finds by name and by comment; preview/apply with hash match and 409 on mismatch; excluded keys never searchable or
writable (tests); exact argv; UI and e2e `e2e/advanced-config.spec.ts` in fake mode.
