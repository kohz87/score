# 3.0.0 Remove the classic shell (brief)

Decision 132 (end of docs/DECISIONS.md) — the owner approved it. Three parts, in this order, one branch:

## 1. Journey chart into Settings › Usage
Move the classic Reports page's **Journey** chart ("tasks, notes, skills and memory over time":
apps/web/src/routes/reports/JourneyChart.tsx, `useJourney`, its toggle and spec on ReportsPage.tsx ~lines 398–520) into
`apps/web/src/bold/BoldUsage.tsx` (Settings › Usage) in the new style (prototype values from
docs/design/bold/prototype.html; agents as AgentGlyph; a11y as the classic chart had: table fallback / labels). Same data
hook and server route; no server change. Unit test + e2e in the Usage spec.

## 2. The task-attempt page framed in the new shell
`/attempts/:attemptId` (routes/attempts/AttemptPage.tsx, linked from bold/agent-more/RunsCard.tsx) → serve it at
`/b/attempts/:attemptId` inside `BoldClassicPage` with Back (exactly like bold/BoldTerminal.tsx frames the terminal);
`/attempts/:id` redirects there keeping query and hash; RunsCard links point there. e2e for open + Back.

## 3. Remove the classic shell
Remove: the classic shell (its layout/nav, `shell/destinations.ts` destinations and their classic page routes: /chat,
/team, /knowledge, /reports, /settings classic pages, classic /watch WatchPage route, the classic /terminal page route
and TerminalRoute if only classic uses it), the "Use the classic view" button (bold/BoldSettings.tsx), the `?ui=` /
`score.ui` classic choice and UiParamBoundary handling of `classic` (the new shell is the only one), classic-only CSS
and tokens (keep every token/style the bold shell or a component it renders still uses — check before deleting), the
classic e2e specs and their screenshots, classic unit tests of deleted code. **Every old classic path keeps redirecting
into the new shell** (keep `boldRedirectFor`/framed-paths style redirects and add any missing: /chat…, /team…,
/knowledge…, /reports → /b/settings/usage, /settings… → /b/settings…), preserving query and hash.

Keep: everything under apps/web/src/routes/** that the new shell still imports (55+ bold files import from routes/ —
those components stay; move nothing in this release unless a file becomes classic-only), the pairing page (/pair),
BoldClassicPage (still used by the terminal and attempts), the theme engine/guard/sanitiser and protected tests.

Done when: no route, import or CSS rule of the removed code is left (typecheck + eslint no-unused + a grep for the
removed component names); `knip`-style dead files listed in your report (don't add a dependency; use tsc/grep); every
redirect has a unit test; the remaining e2e suite passes; the bundle size before/after in the report.

## Constraints
Follow AGENTS.md. No new dependencies. No server or contract changes. Don't commit. No persona names. Never
pkill/killall; never touch ports 8740/8741; e2e with SCORE_WEB_PORT=5751. Never read ~/.hermes or ~/.score. Targeted
tests while working; at the end `pnpm build`, the e2e specs touching what changed (not the full suite — the lead runs it
once after the review), `pnpm lint`, `pnpm format:check`, `pnpm typecheck`, web unit tests.
