Owner: "is there a way to show tps, ttft etc?" → chose **"On each reply + per agent"**.

## Done when
1. **Measured, per run** (Hermes runs and coding-agent runs alike; the `runs` table, apps/server/migrations/0003_runs.sql,
   already has `started_at`, `ended_at`, `output_tokens`):
   - New column `first_output_at TEXT` (migration **0099**; 0098 is taken by 3.9.0): when Score first saw the run produce
     reply text (the first text delta it ingests for that run). Set once, never moved. Find where Hermes run deltas are
     translated (apps/server/src/hermes/live/translate.ts / runs.ts) and where coding events become run rows
     (apps/server/src/runtimes/coding/translate.ts); the fake adapter should produce plausible values too.
   - Where a CLI reports its own figure, prefer it: Claude Code's result record carries `ttft_ms` and `duration_ms`
     (capture: keys `ttft_ms`, `duration_api_ms`, `usage`); keep Score's measurement when absent.
   - Derived (not stored): **TTFT** = first_output_at − started_at (or the CLI's ttft_ms); **tokens/s** =
     output_tokens ÷ (ended_at − first_output_at) seconds, only when both exist and the span is ≥ 0.5 s; **tokens** =
     output_tokens. Anything missing is null, never guessed.
2. **On each reply.** An agent reply (MessageItem in apps/web/src/routes/chat, as used by the bold room and one-to-ones)
   shows a quiet line, e.g. `first token 1.2 s · 48 tok/s · 1,240 tokens`, under the message meta or on hover (follow
   how the reply's existing meta/time is shown; keep it small and muted; nothing for a reply that is still streaming).
   The figures reach the web on the message (contract: an optional `speed: { ttftMs, tokensPerSecond, outputTokens } |
   null` on the agent message, from the run behind it) — update docs/API-CONTRACT.md first.
3. **Per agent.** Settings › Usage (apps/web/src/bold/BoldUsage.tsx, server apps/server/src/http/reports.ts) gets a
   "Speed by agent" card: median TTFT and median tokens/s per agent over the selected period (with run counts), as a
   small table like Spend by agent, "—" where an agent has no measured runs.
4. Tests: migration, the measurement (first delta sets it once; CLI ttft preferred), derivations (null cases), the
   report medians, the MessageItem line, the Usage card.
