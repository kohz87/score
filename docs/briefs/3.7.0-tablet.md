# 3.7.0 Tablet view (brief)

Owner, 2026-10-26: "work on tablet view, the web works for phone and desktop but not tablet"; asked what goes wrong,
chose "Fix all I found". Lead's audit (fake mode, screenshots at 768×1024, 820×1180, 1024×1366, 1024×768, 1180×820,
1366×1024; no horizontal scroll anywhere):

- The shell has ONE breakpoint, `max-width: 860px` (phone layout below, desktop above; `PHONE` constants in
  BoldRoom.tsx, BoldLibrary.tsx, BoldTeam.tsx and 23 CSS rules). Portrait tablets (744–834) get the phone layout;
  landscape tablets (1024–1366) get the desktop layout.
- **Portrait, team room** (`/b` at 768 and 820 wide): the room's content is capped at ~620px and left-aligned with an
  empty right strip; the header (title, ⋯, + Job, Open side panel) is centred on its own and doesn't line up with the
  content below. Must use the width (or centre the whole column consistently, header included).
- **Portrait, one-to-one** (`/b?with=builder`, full-screen sheet): the message column and composer are narrower than
  the sheet and not aligned with the header row.
- **Portrait, Settings › Usage**: the stat cards stack one per row across 768px — use two columns from ~600px.
- **Touch (any orientation)**: controls that appear only on mouse hover can't be reached on a touchscreen. Room messages
  already show their actions under `@media (hover: none)` (bold-room.css); find every other hover-only control in the
  bold shell (grep `:hover` rules that reveal something, `opacity: 0` / `visibility: hidden` / `display: none` revealed
  on hover — e.g. bold-workbench.css ~299; Library rows; Runs; Recipes; Team cards; Search) and make it visible (or
  reachable by tap) under `(hover: none)`. Touch targets ≥ 44px under `(pointer: coarse)` like the phone rules.
- Check the other pages at the six sizes yourself (Team, agent page, screen page, Recipes, Library, Runs, Settings
  sections, Search ⌘K, Start a job, New team dialog) and fix what is cramped, misaligned or unreachable. Landscape
  1024×768 desktop layout: room column 440px + side panel is acceptable; make sure nothing clips (e.g. the Usage table,
  Recipes editor's right panel).
