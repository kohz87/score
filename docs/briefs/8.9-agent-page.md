## Problems to fix
1. Cards touch: no gap between Personality → Coding agent (coding) and Permissions → Agent details (Hermes).
2. Header: the Watch link and a bare pop-out icon are stacked under the name. Design: name, one-line role, status, and on
   the right **Message <name>** (primary, opens the direct room) and **Pause/Resume** (as today's pause control); Watch
   and pop-out become secondary buttons in that action group.
3. Hermes overview grid is 4–5 columns; design is **3 columns** (Model, Skills, Memory / Tools, Routines, Permissions),
   equal-height rows, the design's gaps. Long lists are capped: Skills shows the first ~10 chips + "Show all N" (opens the
   Skills tab), Tools the first ~6 rows + "Show all N" (Tools tab); Memory the first 3 notes.
4. Coding overview is one long card with label/value rows stretched across the page, an empty gap under Workspace, and
   the settings form nested inside. New layout mirroring the Hermes one:
   - **Personality card** like the Hermes one: role as the large text (or "No role yet"), instructions excerpt, "Edit
     personality"; on the right the facts column: CLI (version · state, Check again), Workspace (mono), Quota source.
   - **Grid of 3 cards**: **Limits left** (the 8.1 meters + floor mark), **Model** (current model large like Hermes'
     Model card, the 8.5 picker behind "Change model"), **Access** (permission level in plain words, the limit floor,
     the read-access warning; edited in place with Save in that card). Supervision/host-check text goes as a small
     line in the CLI fact (expandable), not a floating paragraph.
5. "Agent details" (Hermes) and "Danger zone" (both): at the bottom, after a section gap, visually separate.
6. The quota floor field must be left-aligned (an earlier CSS fix didn't take: find what centres it).
