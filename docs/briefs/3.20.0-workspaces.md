## Model
- A **workspace** is a named folder. **Agents are assigned** to workspaces (many to many). A **room** may be set to one
  workspace (the chats redesign will call rooms chats; today: the team room, team rooms, directs).
- **Coding agents** (Claude Code, Codex, Antigravity): a turn in a room whose workspace the agent is assigned to runs
  in that workspace's folder; otherwise in the agent's own folder (`coding_agents.workspace`, unchanged, kept as the
  fallback). Orchestration worker steps are unchanged (their frozen policies keep the agent's own folder).
- **Hermes agents**: Hermes' API has no per-turn folder (checked 2026-11-03: `/v1/runs` takes none; the folder is the
  profile's `terminal.cwd`). So a Hermes agent assigned to workspaces gets **one of them as its folder**: an action
  "Use as <agent>'s folder" sets it through the existing `setWorkspaceCwd` port method (only for an assigned workspace).
