  % and reset times.
- `agy` self-updates in the background.

## Build (follow 7.2's driver model in apps/server/src/runtimes/coding/)
1. Driver `antigravity`: tested version **1.3.3** (exact); version checked before **every** turn (self-update) → untested
   version pauses the agent with the existing "confirm version" flow.
2. Turn: spawn by argv in the agent's workspace (cwd), stream-json parsed with zod (unknown events counted, never
   crash); text deltas → reply; tool steps → tool cards + Watch frames (run_command → terminal frame, file tools → file
   frames, browser tools → a generic frame; redact before storing, assembled not per chunk); `denied_actions` shown as a
   card ("Antigravity refused: RunCommand"); usage → run tokens (cost unknown); conversation continuity per room via
   `--conversation <id>` from the init event.
3. Permission levels — map conservatively; the lead live-verifies each before it is offered:
   - **read-only** → `--mode plan` (+ `--sandbox`), request-review (denies writes/commands).
   - **workspace-write** → `--mode accept-edits --sandbox`.
   - **full access** → `--dangerously-skip-permissions` (password + warning like the others).
   Levels not yet verified are shown disabled with "not verified for agy yet". Also warn that agy can browse the web,
   generate images, schedule and run sub-agents.
4. Stop: process-group escalation (fix-l), slot held until the group is gone.
5. Quota: `/usage` parsed into the existing quota display (runtime card / Reports).
6. Team › Add agent › Coding agent offers "Antigravity (agy)" when the binary is found.
