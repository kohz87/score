## Design (from the lead)
- **Plugin** (`hermes-plugin/score_bridge/`): today a string over `LEAF_CAP` (16 KB) is dropped ("[omitted: N chars]").
  For the `terminal` tool's result output (and `execute_code` output), keep a **tail** instead: take the last
  (cap + 4 KB margin) chars, redact with Hermes's forced redaction (`redact_sensitive_text(..., force=True)` through
  `hermes_private.py`) **and** `local_redact`, then drop the margin from the start and cap at 16 KB; mark it as a tail. Never
  send raw text; keep the whole payload ≤ 64 KB. Capture cwd and exit status where Hermes provides them.
  **Never capture arguments or results of `browser_vault_*` tools or any tool whose args carry credentials** (send only the
  tool name and status; the server shows "Filled a saved login" / "Used the password vault").
- **Server**: migration **0016** `watch_frames` (seq per agent, at, agent_id, run_id, surface, payload JSON, caption,
  marker kind) written in the same ingest transaction as the tool observation; a **second redaction pass** (`redact()`)
  before storage; terminal frames from `terminal`/`execute_code` (running at pre, ok/error at post), editor frames from
  `write_file`/`patch` via `editorFramesFromTool` (always an array; task 4.2, merged in
  `apps/server/src/domain/watch-diff.ts`), browser frames from browser tools (url/title; screenshots via
  the media store, task 4.3 — store `imageUrl: null` for now). Captions: short, plain ("Ran pnpm test", "Edited
  src/feed.ts", "Opened example.com").
- Endpoints (contract §4): `GET /api/agents/:agentId/watch?from=&limit=` (frames + markers, `live` when the agent has an
  active run), `GET /api/watch/overview`. Stream: `watch.frame` events if the contract has them, else refetch on
  `run.*`/tool events (check §2; propose a contract addition in your report if needed).
- Retention: frames older than 7 days are deleted by the existing retirement sweep (hub/retire.ts).
- Fake mode: the scenario's tool calls produce frames (neutral content).
