# 5.34 Responsive pass: phone and tablet (owner request 2026-10-10)

Owner: "the tablet and mobile interface is horrible and sorely misaligned. we could use hamburger menu etc to tidy it
up." Desktop (≥ 1024 px) stays as it is (it matches docs/design/*). Audit captures (fake mode, 390/768/1024):
`/home/raven/.claude/jobs/999c85f0/tmp/responsive/*.png` — look at them first.

## Breakpoints
Phone < 600 px, tablet 600–1023 px, desktop ≥ 1024 px (one set of CSS custom properties / media queries, used
everywhere; replace ad-hoc breakpoints where you touch them).

## Shell
- Below 1024 px: top bar = logo, **hamburger button** (left of the logo or right before search — pick one, consistent),
  search icon, avatar. The destination nav moves into a **slide-in drawer** from the left: the seven destinations with
  the Now indicator dot, Terminal (when available) and the Now sub-views; current page marked; closes on navigation,
  Esc, backdrop click; focus trapped while open and returned to the hamburger; `aria-expanded`/`aria-controls`;
  body scroll locked; reduced motion = no slide. CSS transitions only (no new dependency; the owner mentioned
  anime.js — not needed for this; note in the report if something would benefit).
- Consistent 16 px side gutters on phone, 24 px on tablet; no horizontal page scroll at 360, 390, 768, 1023 on any
  route.

## Pages (phone and tablet)
- **Now:** hero heading scales down (clamp; ≤ 2 lines on phone); Score/Flow/Routines tabs and Pause everyone on one
  row (Pause as an icon+label that fits); the timeline gets a sticky agent column and a horizontally scrollable time
  area (no clipped bars), or on phone a vertical "per agent" list — pick what reads better and show both screenshots.
- **Chat:** tablet = two panes (conversation list as a collapsible sidebar or drawer + the room); phone = the room
  first with a "Conversations" button opening the list as a drawer; New chat / New orchestration as compact buttons in
  that list, not full-width bars on top of the room.
- **Tasks:** filters in one horizontally scrollable chip row (or a "Filters" button with a sheet on phone); New task stays
  visible; board columns scroll-snap one column per screen on phone (column tabs with counts above), two on tablet.
- **Team / agent page:** agent list becomes a compact switcher (select or drawer) above the agent page; the agent hero
  card shrinks; tabs scroll horizontally with fade edges.
- **Settings:** section nav becomes a select / disclosure ("Section: Models and keys ▾") so the section content comes
  first.
- **Knowledge, Reports, Flow, Watch, orchestration views, Terminal:** check each; fix overflow and alignment
  (Knowledge's note tree as a drawer on phone).
- Dialogs (New orchestration, Add agent, …) become full-screen sheets on phone.
