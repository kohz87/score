## Design (from the lead)
- **Read model** (contract §7, types `TaskSummary`/`TaskDetail`): add `HermesPort.listTasks(filter)` and
  `getTask(id)`. Live: read `kanban.db` read-only through the existing readers in
  `apps/server/src/hermes/live/kanban.ts` (extend them; never write). Fake: the fake port's tasks from the scenario.
  Column mapping (docs/SPIKE.md): `triage|todo|scheduled|ready` → `planned`; `running` → `working`; `review` →
  `in_review`; `blocked` → `needs_you` (every block needs a human; badge `blocked`, or `needs_you` for
  `block_kind ∈ {needs_input, capability}`); `done` → `done`; `archived` hidden unless requested. A task with an open
  visible approval (approvals table, `refs` task or `kanban_task_id`) is `needs_you` with `pendingApproval` set.
  `key` = `T-<kanban rowid>`. `dependsOn`/`blocks` from task links; `activity` from `task_events` + comments (newest
  50); `runIds` from `task_runs`; `progress` = done steps / steps while working, else null.
- **Endpoints**: `GET /api/tasks?room=&agent=&needsYou=true&column=` → `{ asOfSeq, columns }`; `GET /api/tasks/:taskId`;
  `POST /api/tasks` (`hermes kanban create` with `--assignee`, `--body`/`--body-file -`? use `--body` with the steps
  rendered into the body; then re-read; respond `TaskDetail`); `PATCH /api/tasks/:taskId` (title/body/assignee/
  steps: find the CLI verbs in `hermes kanban --help` (`../reference/hermes-agent/hermes_cli/kanban.py`); fields without a
  CLI verb → 501 with a clear message); `POST /api/tasks/:taskId/actions` — **keep** 1.13c's `comment`/`unblock`
  behaviour and add `start`, `block`, `request_review`, `request_changes`, `complete`, `archive` using the matching
  CLI verbs (exact argument arrays; user text as `--opt=<text>` or after `--`; 409 when Hermes rejects; re-read and
  return `{taskId, action, hermesStatus}`). Human guard + `Idempotency-Key` on all mutations.
- **Steps model** (`apps/server/src/domain/steps.ts`, pure): parse `- [ ] text` / `- [x] text` lines (also `*`,
  indentation ≤ 3 spaces) into `TaskStep[]` with stable ids (hash of position + text); `writeSteps(body, steps)`
  replaces only the checklist block (first contiguous checklist) and preserves every other byte; round-trip tests.
- **Stream**: live: a Kanban tailer (reuse `tailTaskEvents`, checkpoint by event id through ingest, identity
  `kanban-event:<id>`) emits `task.upserted` and `task.activity`. Fake: unchanged scenario events.
