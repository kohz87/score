1. **Start a job** (`apps/web/src/bold/BoldStartJob.tsx`, lead-decides mode): an optional, folded section "Check before it
   finishes". Fields: command (one line, monospace; placeholder `pnpm test`), folder (absolute path; prefill with the
   workspace of the first selected coding agent if one is known, else empty), "Also run after every step" toggle
   (`when: 'each_step'`), timeout in minutes (default 10, max 60). One sentence of help: "Score runs this command in the
   folder, without a shell. The job can only finish as a success after it passes. Only you can change it."
   When a check is set, starting the job needs the security password or passkey: reuse exactly what the live session /
   terminal does for `fresh_auth_required` (see `apps/web/src/bold/BoldTerminal.tsx`, `routes/terminal/TerminalPage.tsx`):
   confirm first, then POST. Show the server's `invalid_check` / `second_factor_not_enrolled` messages inline.
2. **The job's view** (find where the bold shell shows a lead-decides job's detail: steps, gates, finish; e.g. the run side
   panel / `bold/room/RunSafetyRequests.tsx` and its neighbours): a **Check** card when `detail.check` is non-null:
   - the command (monospace) and folder, "before finishing" or "after every step and before finishing";
   - the latest runs (up to 5): outcome pill (passed / failed / timed out / could not run / interrupted / stopped /
     running / queued), exit code, who asked (lead / after a step / you), time; "counts for finishing" when `current`;
     expandable output (monospace, scrollable, max-height);
   - **Run check** button (POST check/run) while the job is running or paused;
   - **Finish without a passing check** (POST check/waive) while running/paused and not waived: a decision surface, so it
     carries `data-protected` and is added to the protected list (`apps/web/src/styles/protected.css` and its test) per

3. Copy styles from `docs/design/bold/prototype.html` / existing bold cards (tokens under `[data-ui='bold']`, `bold-`
