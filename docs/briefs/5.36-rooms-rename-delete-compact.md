# 5.36 Rooms: rename, delete, compact context (owner request 2026-10-11)

Owner: "there's no compact context function? cannot delete old rooms (orchestration)? assign name to rooms?"

## 1. Rename
`PATCH /api/rooms/:roomId { name }` exists; add **Rename** to the room ⋯ menu (RoomMenu.tsx) and to the room header (click
the name): inline edit, Enter saves, Esc cancels, validation as the API (`#tag` words keep working). Orchestration/workflow
rooms may be renamed (organising action, allowed while owned like pin/tags).

## 2. Delete
- **H** `DELETE /api/rooms/:roomId` `{ confirm: <room name> }` → `204`. Score-side only: the room, its messages, message
  runs, attachments' message links, versions, summaries, shares, pins/tags; agents' Hermes sessions are **not** touched
  (say so in the dialog). Media files referenced only by this room are released (existing media-ref rules).
- Refused `409 room_busy` while any turn in the room is running/queued (Stop first); `409 orchestration_owned` while an
  orchestration/workflow owns it. A finished + released run's room may be deleted: the run's records are pruned in the same
  transaction (reuse the executor's prune path, keeping journal tombstones), then the room.
- Direct rooms (agent DMs) can't be deleted (they are the agent's home) — only cleared? No: hide Delete for directs.
- UI: ⋯ → Delete room… → dialog listing counts (messages, files, runs) with "Export first" (existing room export) and a
  typed-name confirmation; afterwards navigate to Chat home. Stream `room.deleted { id }`; other tabs drop it.
- Archive stays as the gentle option.

## 3. Compact context
- Hermes compacts automatically near the context limit; manual `/compress` exists in the Hermes CLI and messaging
  gateways but the API server ignores slash commands. Add a **bridge command** `compact_session` (like rewind, PLAN 5.33):
  Score → bridge command `{ profile, sessionId, keepRecent?: N }` → the plugin calls Hermes's own compressor for that
  session **only through `hermes_private.py`**, under Hermes's transcript lock, refusing while the session has a run in
  flight; reports `{ before: { messages, tokens }, after: {…} }` or a reason. Commands carry `expiresAt` like rewind.
- **H** `POST /api/agents/:agentId/sessions/:sessionId/compact` `{ keepRecent? }` → `202 { commandId }`; result over the
  stream (`session.compacted` / failure). Refused for coding agents (`not_supported`) and for sessions owned by a running
  orchestration/workflow attempt.
- UI: in a room, the agent's context meter (composer footer "builder: 54k of 128k tokens") gets **Compact**; `/compress`
  in the composer now runs it for the target agent (replacing today's explanation) with a confirm ("Hermes will summarise
  older turns; recent N stay word for word"). Show the before/after token counts.
- Tests: plugin pytest with a fake Hermes store (no real Hermes), server tests with the fake adapter, e2e on fake mode.
  Live check later by the lead on `scoretesta` only.

## 4. Context meter (owner, 2026-10-11)
"Include a circular meter like Claude that can be opened with details on what is using the context, how full is it."
- **Meter:** a small ring next to each agent in the room's composer footer (replacing the flat "54k of 128k tokens" bar):
  fill = used / window, colour steps (normal → amber ≥ 75 % → coral ≥ 90 %, never colour alone: the % is in the
  tooltip/label), accessible name "builder context: 42 % of 128k". Unknown window → ring shows tokens only, no %.
- **Details popover** (click/Enter): how full (used / window, %), a stacked bar + list of **what is using it** — system
  prompt / personality, tool definitions (incl. MCP), memory, skills, conversation messages, compressed summaries,
  attachments/files, other — each with tokens and %; the model; when it was measured; "Hermes compacts automatically at
  N %" (if the setting is readable); the **Compact** button (section 3) with the before/after after it runs.
- **Data:** a bridge query `context_breakdown { profile, sessionId }` answered by the plugin from Hermes's own context
  accounting (what the Hermes `/context` command reports — find it in the reference; private calls only in
  `hermes_private.py`, read-only, no model call). **S** `GET /api/agents/:agentId/sessions/:sessionId/context` →
  `{ window, used, measuredAt, model, parts: { kind, label, tokens }[] | null, autoCompactAt: number | null }`; falls back to
  today's `AgentContext` totals (parts `null`, popover says the breakdown isn't available) when the plugin can't answer
  (old plugin, coding agents). Cached ≤ 30 s; refreshed after each turn and after Compact.
- Tests: plugin (fake store), server, web (ring states, popover, fallback, a11y), e2e fake mode, baselines viewed.
