## Part A — Tasks page (apps/web/src/bold/BoldTasks.tsx, bold-tasks.css)
Approved mock-ups (binding): `docs/design/bold/mockups/20-tasks.dc.html` (board + the open task sheet in edit),
`20-tasks-new.dc.html` (the New task dialog), `20-tasks-phone.dc.html`.
1. **+ New task** beside the "Tasks" heading (small outline pill with a + icon, 36px; 44px on a phone). It opens the
   New task dialog: What needs doing (required), Details, Who does it (agents that can take work), In which chat
   (the user's chats; optional), Start: Now / Plan it for later; Create task posts once with an `Idempotency-Key`
   (a retry reuses it); the line "The same as typing /assign @agent … in a chat". The new task appears on the board
   (stream `task.upserted`) and opens selected.
2. **Edit** in the task sheet: title, description, who's doing it, Save changes / Cancel (PATCH only what changed);
   errors in plain words.
3. **Move it:** Ask for review, Block, Mark done (and Start for a planned one) through the actions route; only the moves
   that make sense for the task's column are shown.
4. **Archive…** at the bottom of the sheet with the mock-up's note; it asks first (a confirm in place, protected like
   the other decisions: `data-protected`, on the protected list), then archives; an archived task leaves the board.
5. Keep every existing needs-you surface (Allow/Don't allow, Unblock, comments) as it is.
