## Done when
1. **Editor and preview.** Replace the workspace textarea with the CodeMirror 6 editor used by Knowledge (reuse
   `routes/knowledge/MarkdownEditor.tsx`'s theme/highlight setup; factor a shared `components/CodeEditor.tsx`), with
   language by extension for Markdown, JavaScript/TypeScript, JSON, CSS, HTML, Python, YAML, shell (only `@codemirror/lang-*`
   packages already in the lockfile; any other language plain — ask the lead before adding a package). Markdown files get a
   rendered Preview toggle using the chat `Markdown` component (no raw HTML). Keep etag save/conflict behaviour. Lazy-load
   the editor like Knowledge.
2. **Git badge.** When the workspace root (or a parent) is a git repository, the header shows the branch and the number of
   changed files (`git -C <root> status --porcelain=v1 -b`, read-only, execFile, timeout, hooks irrelevant for status;
   new `GET /api/agents/:id/workspace/git` → `{ branch; changed; ahead; behind } | null`, contract §8). Never run any
   writing git command.
3. **workspace:// links.** In chat Markdown, links `workspace://<path>` (and `workspace://<agentId>/<path>`) open that
   file in the agent's Workspace tab (route `/team/:agentId/workspace?path=`); invalid/blocked paths show the normal error.
   Document the scheme in the contract and in USER-GUIDE so agents can be told to use it.
4. **Resizable panel.** The tree/file split is drag-resizable (pointer + keyboard via a separator with `aria-valuenow`),
   width remembered per browser (localStorage in try/catch); mobile keeps two screens.
5. **Todo panel.** If Hermes exposes the agent's todo list (find it: the `todo` tool's state, readable read-only through
   state.db or the run events; inside the adapter boundary), show a live "Todo" card on Team › agent › Overview and in the
   Now thread for the active run (items with status). If Hermes keeps it only in memory, write
   `docs/proposals/hermes-todo-api.md` and report instead.
6. Tests for each, e2e on the fake adapter (editor save, Markdown preview, git badge with a temp repo, workspace:// link,
   resize), visual baselines for the Workspace tab checked by eye.
