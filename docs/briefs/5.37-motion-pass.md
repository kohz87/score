# 5.37 Motion pass with anime.js (owner request 2026-10-11)

Owner: "how can we use animejs.com to beautify the interface? and where" → lead proposal accepted ("go ahead with the
motion pass"). Dependency: `animejs@4.5.0` (MIT, no dependencies) — the lead adds it to `apps/web` before you start; import
only the modules used (`animate`, `svg`, `stagger`, `utils`…), and load it only in the routes that use it (lazy chunks).

## Where (in this order)
1. **Orchestration / workflow live diagram** (`routes/orchestrations/` LiveDiagram + the workflow run view): dots follow
   the real SVG edge path (`svg.createMotionPath` on the edge `<path>`), lead → step on assign, step → lead on result,
   token dots on workflow edges; node state changes animate (queued → running ring → done check) with a short stagger
   when several change at once. Keep the existing event queue/pacing semantics (≥ 300 ms per effect, ordered, never
   invented); replay at 1× uses the same motion, 4×/16× stay as highlights.
2. **Context ring** (`routes/chat/ContextMeter.tsx`): the ring's stroke animates to the new value; after Compact it drains
   to the new % while the token figure counts down (`utils` number tween); first render shows the value without motion.
3. **Needs-you cards and approvals** (Now, Chat inline approval, orchestration/workflow decision cards): one gentle
   entrance (fade + 8 px rise) and a single attention pulse on arrival; never looping; no motion when re-rendered.
4. **Now › Score timeline**: a new hand-off connector draws itself (`svg.createDrawable`) and a new block grows in.
5. **Reports**: charts draw in once on load; headline totals count up.

## Rules
- Durations 300–600 ms, calm easing; motion explains a change, never decorates idle UI; nothing animates on every
  stream tick (only on state transitions).
- `prefers-reduced-motion: reduce` → no animation at all (final state immediately); one shared hook/util decides.
- No information only in motion: text, log lines, labels and aria stay the source of truth.
- Visual baselines run with animations disabled (Playwright `animations: 'disabled'` already) — make sure final states
  are rendered deterministically; add unit tests for the reduced-motion path and for "first render doesn't animate".
- Plain CSS stays for drawer/dialog/hover transitions.
- Bundle: report the added gzip size per chunk; the main entry chunk must not grow.

## Done when
Web tests, the orchestration/workflow/chat/now/reports e2e + visual specs green, baselines unchanged except intentional
(list them), a short screen recording is not needed — the lead reviews by stepping through with screenshots at key frames
you capture (e2e helper that pauses animations at 50 %); `pnpm check` green.
