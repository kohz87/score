# 3.3.0 Bot Screen: the web card (brief)

Server side is done (commit "3.3.0: Bot Screen server side"). Read the design note docs/briefs/3.3.0-bot-screen.md,
decision 135 (end of docs/DECISIONS.md) and the contract lines for `GET /api/agents/:agentId/bot-screen` and
`…/bot-screen/frame` in docs/API-CONTRACT.md (Watch view section). Schema: `BotScreenStatusSchema` in
packages/contract/src/watch.ts. The fake adapter's `builder` has a running screen (960×600, changes every second);
every other demo agent's screen is off.

## Build
On the agent's screen page (`/b/screen/:agentId`, apps/web/src/bold/BoldScreen.tsx + bold-screen.css), a **"Live
screen"** card at the top of the main column, above the replay's surfaces:
- Header: "Live screen" + a small "Read-only" label (same style as the existing "builder's screen · Read-only" header).
- `running`: the frame as an `<img>` scaled to the card width (keep aspect ratio from width/height), alt
  "<agent>'s screen, live". Poll the status about once a second while the page is visible (`document.visibilityState`)
  and the card is open; load the frame URL with a cache-busting query of `frameSeq` only when `frameSeq` changed (the
  server answers 304 on If-None-Match too). No pointer, keyboard, drag or context-menu handlers on the image; it is a
  picture, not a remote desktop (AGENTS.md: "Watch is an event replay, not a remote desktop").
- `off`: one quiet line "The screen is off." — and when the agent has never had one, the card collapses to that line.
- `sandboxed`: "This screen runs inside the agent's sandbox, where Score can't show it."
- `human`: "Someone has taken over this screen. Score hides it while they work." (this one is a privacy statement:
  mark the line `data-protected` and add it to the protected list, styles/protected.css and its test, per AGENTS.md
  design rules).
- `unavailable`: "Score can't show this screen." plus `reason` when present.
- A "Hide" / "Show" toggle (collapsed state per device in localStorage, wrapped in try/catch); while hidden, no polling.
- Phone width: the card is full width, image scaled; no horizontal scroll.
- Use TanStack Query (as the page's other reads do) with `refetchInterval` gated on visibility and the open state.
- Add the endpoint calls in the web data layer where the other watch reads live (apps/web/src/data/…).
