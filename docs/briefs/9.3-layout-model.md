# 9.3 Layout model (PLAN 9.3; design docs/briefs/9-themes.md §2 layout, §7; decision 90)

Goal: every `layout`, `shape` and `background` option of `ThemeManifest` (packages/contract/src/themes.ts) changes the
real app, through the theme engine (apps/web/src/themes/engine.ts, attributes `data-nav`, `data-width`, `data-radius`,
`data-elevation`, `data-surface`, `data-border`, `data-chat`, `data-density`) and a `useLook()` layout config.

Work:
1. **Shell / nav**: `top` (today), `left` and `right` rail (8.3's rail; right mirrored), `launcher` (one menu button
   top-left opening the drawer, plus the ⌘K palette; maximum content). Phone width: all fall back to today's top bar +
   drawer. Same links, order, keyboard and screen-reader behaviour.
2. **Menu**: `layout.menu` order, labels and hidden destinations; Settings can never be hidden (added last if missing);
   Needs-you dot stays on Now wherever it is.
3. **Content width**: `narrow` (~960px), `wide` (today), `full`.
4. **Now cards**: `layout.now.columns` + `cards` (timeline, room, needs-you, made-today, todo, composer) with spans;
   needs-you always present (added if missing). Today's Now = the default config.
5. **Chat**: `messages: plain` (today) or `bubbles` (own messages right in a bubble using `--bubble-own`/`--bubble-own-ink`,
   agents left with AgentGlyph); `roomList: left | right | hidden-until-opened`.
6. **Component variants** in `apps/web/src/themes/variants.css` for every card/panel family (not just cards): elevation
   flat/raised/floating, surface solid/glass (`backdrop-filter`, readable fallback), border none/hairline/strong, radius
   sharp/soft/round/px, density compact/comfortable/airy (0.85/1/1.2).
7. **Background**: image (asset URL), cover/tile, dim overlay — behind content, never behind protected surfaces' text
   without their own solid background.
8. **User view** (8.4) reads `views.user` overrides.
Protected surfaces (9.2) keep their guarantees in every combination (extend the hostile e2e with layout options).

Done when: each option has e2e + visual baselines (light/dark/phone where relevant) using mocked theme manifests (the
9.2 visual fixture), the default Score look stays pixel-identical (no existing baseline changes), `pnpm check` + full e2e.
Coordinate: 8.9 (agent page) is being finished in parallel on another branch — don't restyle the agent page itself.
