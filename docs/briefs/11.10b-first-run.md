# 11.10b: First run and starter recipes (DeepSeek)

PLAN 11.10b: "boards 08, 09: Hermes found, pick agents, pick the lead, keep Score running; starter recipes. Done when: e2e
from an empty SCORE_HOME in fake mode." The empty room (board 09) is built by 11.4a with the room column; this task is
the first-run screen and the starter recipes.

Source: prototype `vFirstRun()` and its CSS; board `08-first-run.dc.html`.

## Build
- `BoldFirstRun` on `/b`, shown when the team room has no lead yet and nobody has finished first run on this device
  (per-device flag, wrapped in try/catch), and on `/b?first=run` (the link in `bold-links.ts`). It is a page in the main
  column, not a modal; the shell's dock and tab bar stay.
- **Hermes found**: from `GET /api/system` (contract § System status: Hermes version, gateway, bridge); when Hermes is
  missing or degraded, say what is wrong in plain words and link to the classic setup help; never fake "found".
- **Who's on the team?**: the team room's members are the team's agents and can't be changed (contract: "its members
  follow the team's agents at every start"), so show them as a list with `AgentGlyph` (colour + shape), with "Add or
  remove agents on the Team page" linking to `/b/team`. Prototype difference: checkboxes become this list (no API) —
  say so in the report.
- **Who leads?**: a select of the members, saved with `PATCH /api/rooms/:roomId { leadAgentId }` on "Open the team room"
  (the team room's id from `GET /api/team-room`). Required: Score never guesses the lead (decision 114).
- **Keep Score running**: Score has no API to install itself as a service, so show the one command from
  `docs/SETUP.md` (`scripts/score install` or what SETUP says; read it) with a copy button and "Already running as a
  service" when `GET /api/system` says so (if it doesn't, just show the command). Never claim it was set up.
- **Starter recipes**: offer the prototype's starter recipes ("Build, then review", "Write, review, design", "Research
  report") as checkboxes; chosen ones are created through `POST /api/workflows` (contract §15) as workflows the recipe
  editor (11.10d) shows; skip names that already exist; agents in them use the team's ids when present, else leave the
  step's agent empty for the person to pick (the validator will flag it).
- "Open the team room" saves, sets the device flag and goes to `/b`.
