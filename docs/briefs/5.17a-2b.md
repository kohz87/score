# Brief 5.17a-1 stage 2b: Kanban attempts — web pages

**Design:** `docs/briefs/5.17.md` (v5 §H, v4 §5–§6) and the stage 2a contract on main (`docs/API-CONTRACT.md` §1, §2,
§4, §7, §8, §9: `AttemptSummary`, `TaskRef`, `attempt.updated`, `NowSnapshot.unattributed`, `checks[].verdict`,
`LaneBlock.observationEndedAt/provenance/order`, nullable handoff agents, `FlowNodeDetail.tools: null` + `attempts`,
`Reports.unattributed`, `TaskDetail.unresolvedRunLinks`, `AgentHistoryItem.attempt`, `GET /api/attempts/:id`). Follow the
look in `docs/design/` (HTML for exact colors/radii); agents are always color + shape (`AgentGlyph`); unattributed work
uses a neutral glyph that is not an agent shape.

## Scope (web only; server changes only if a contract gap is found — ask first)

1. **Now:** the `unattributed` lane (header "Unattributed", neutral glyph) under the agent lanes; blocks with
   `observationEndedAt` end there with a dashed "no longer observed" tail (text alternative for screen readers);
   `provenance: 'partial'` blocks show "provenance unknown" in their tooltip/details; checks render `passed` /
   `changes requested` / `not verified` (neutral, never red for unknown); sort blocks by `order` (never by id);
   handoffs to/from a null agent draw to the Unattributed lane.
2. **Flow:** node detail lists attempts (status, agent or "unattributed", start/end, evidence); `tools: null` reads
   "not observed"; brief spend shows "partial" when `spendUsd` is null with attempts present.
3. **Reports:** the `Unattributed` row in By agent and in the CSV (already server-side), working time only for proven
   attempts (label the column note).
4. **Team › agent › History:** attempt items with their status; "an earlier attempt (details not kept)" for unresolved
   legacy links.
5. **Tasks drawer:** `unresolvedRunLinks` shown as that same line.
6. **Attempt detail page** `/attempts/:id` for references with `task.current === false` or `taskId: null`: frozen task
   snapshot with "from an earlier copy of the board"; read-only, no actions, no Watch link ("not observed").
7. **Stream + notifications:** `attempt.updated` invalidates Now, Flow, Reports and Team history queries; a notification
   for an attempt opens the task when `task.current`, otherwise the attempt page — never a Watch URL.

## Done when

Web unit tests for each item; one e2e spec against the fake adapter with `SCORE_KANBAN_ATTEMPTS=1` seeded attempts
(the fake adapter may need a small seeding hook — say so); visual baselines for Now with an unattributed lane and a
dashed tail, checked by eye; `pnpm check` green; flag off renders exactly as today.
