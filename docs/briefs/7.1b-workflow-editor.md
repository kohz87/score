# Brief 7.1b: Workflow editor and run view (web)

**Design:** `docs/briefs/7.1-workflow-builder.md` (v8.3 → v8; UI section of v7) and the 7.1a contract (API-CONTRACT §15,
`packages/contract/src/workflows.ts`). Reuse the 7.5 orchestration pages (live diagram, log, replay, decision cards,
Now "Needs you") wherever possible.

## Pages
1. **Flow › Workflows** list: name, latest version, used/unused, last run status + graphOutcome; New workflow; Duplicate;
   Delete (unused only); Export (scrubbed, with the diff shown and fields removable).
2. **Editor** (Flow canvas in edit mode): palette (agent with AgentGlyph per agent, gate, branch, join, end), drag to
   place, connect ports (agent ok/failed, gate ok/rejected, branch rules + default), inspector per node (agent +
   instruction template with `{{inputs.x}}` / `{{nodes.N.output|verdict}}` autocomplete, retries 0–2, estimate;
   gate question; branch rules: verdict / outcome / output contains + required default; onFailure / onReject explicit),
   workflow inputs editor, **live validation** (every §15 ValidationCode shown on the node/edge it concerns, plain words),
   Save as new version (conflict on a stale base version → explain and reload). Keyboard: add/connect/delete nodes,
   move with arrows; the canvas has an accessible outline list as its text equivalent.
3. **Start dialog**: inputs, budget, deadline, unknown spend (pause / continue), gate policy (gates-only default /
   every-step), the 7.5 acknowledgement text, preflight (minus MCP checks), agent mapping with exact incarnations.
4. **Run view**: the 7.5 live diagram laid out from the definition graph (gate nodes as diamonds, branches, skipped
   nodes struck/faded, tokens on edges as the moving dots), live log, replay; node inspector with attempts, consumed
   results (revision), verdict, output; status = executor status + named graphOutcome with the note
   ("Graph reached the end — 1 abandoned attempt not confirmed ended"); Needs-you cards: node gate (frozen evidence),
   assignment gate (every-step), Retry, remap (exact plan), refusal limit (Try again / Stop), budget/unknown spend;
   Pause/Resume/Stop; Re-run with the same or edited inputs.
5. Now "Needs you" and Chat room panel integrate workflow runs like orchestrations (run's room is workflow-owned).

1440, 768, 390, dark) viewed by eye, responsive rules from 5.34; `pnpm check` and `pnpm e2e` green. No new dependencies
(SVG/CSS on the existing Flow canvas).
