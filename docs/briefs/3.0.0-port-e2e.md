# 3.0.0 Port the deleted e2e specs to the new shell (brief)

The classic-shell removal (commit 032dfb6f on task/3.0.0-classic-removal) deleted 72 e2e specs. Most test features that
still exist in the new shell (`/b`), only through classic pages. **They must be ported, not lost.** Restore your group's
files with `git checkout 032dfb6f~1 -- <file>` (and any helper/fixture file they import that the commit deleted — check
`git diff --name-status 032dfb6f~1 032dfb6f -- e2e`), then rewrite navigation and selectors for the new shell.

## Rules
- **Never weaken an assertion.** Every `test(...)` of the old file ends as one of: (a) ported (same behaviour proved on
  the new shell), (b) already covered by an existing new-shell spec — name the spec and test that proves the same
  thing, (c) dropped because the feature itself was removed by decision 131/132 (classic layout, nav rail, menu order,
  page width, classic-only colour groups) — say which. Report this as a table.
- Safety and consent tests (themes, protected surfaces, reach consent, approvals, sign-in) are (a) unless an existing
  spec provably covers the identical assertion.
- A port that finds a real product bug in the new shell: fix it (web only; no server/contract change — report if one is
  needed) and say so.
- Old paths redirect (shell/framed-paths.tsx classicRedirectFor): /chat→/b, /chat/:id→/b?room=, /team→/b/team,
  /knowledge→/b?library=1, /knowledge/<p>→/b?note=<p>, /settings…→/b/settings…, /reports→/b/settings/usage,
  /watch/:id→/b/screen/:id, /runs/:id→/b?run=. Navigate to the new paths directly in the specs.
- Screenshot baselines: only for specs that had them and still make sense; check every new image by looking at it.

## Constraints
Follow AGENTS.md. No new dependencies. Don't commit. No persona names. Never pkill/killall; never touch ports
8740/8741; use your assigned SCORE_WEB_PORT (the attempts spec uses port+1, so ports are 10 apart). Never read ~/.hermes
or ~/.score. Run only your group's specs (the lead runs the full suite once at the end). lint, format:check, typecheck.

## Report (under 250 words)
The per-test table (old test → ported / covered by <spec: test> / dropped: reason), product bugs found and fixed, results.
