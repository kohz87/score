Owner (2026-10-19): the agent icon is "too generic"; wants bots like the preview's "all three combined" (face + squish
motion + thought dots, no tile/border), chibi characters as a per-agent alternative, many more shapes ("cloud,
cylinder etc"), and to import their own design (one image, Score animates it). Generation from a concept comes later.

`/home/raven/.claude/jobs/999c85f0/tmp/agent-faces.html` (also https://claude.ai/artifact/2cSwUQMAEnz9jpwoTaij6B).

The contract is written (lead): `packages/contract/src/types.ts` (`ShapeSchema` with 20 shapes, `AgentLookSchema`,
`AvatarRevSchema`, `AgentStyleSchema` with optional `look` and `avatar`, `AgentStylePatchSchema`) and
`docs/API-CONTRACT.md` (the `PATCH …/style` line and "Agent pictures"). Don't change it without asking the lead.

## 10.2a — server
1. Migration **0078**: rebuild `agent_styles` with the 20-shape CHECK and add `look TEXT NOT NULL DEFAULT 'bot'
   CHECK (look IN ('bot','chibi'))` and `avatar_rev TEXT` (nullable); add the same two columns to `coding_agents`
   (check how its shape is stored/validated). Forward-only; existing rows keep their style.
2. Styles read and written everywhere they are today (`domain/agents.ts`, `domain/profiles.ts`, `http/agents.ts`,
   coding agents create/patch/summary) carry `look` and `avatar`. `PATCH /api/agents/:id/style` takes
   `AgentStylePatchSchema` (coding agents too, or their own PATCH — follow the contract) and emits `agent.updated`.
3. Avatar routes per the contract: `PUT` (multipart, one file), `DELETE`, `GET ?rev=`. Type from bytes: PNG (IHDR),
   JPEG (SOF0/SOF2 dimensions), WebP (VP8/VP8L/VP8X; refuse animated VP8X), extension must agree; size ≤ 2 MB; each side
   32–2048 px; refuse anything else (SVG included). Storage `$SCORE_HOME/avatars/<agentId>/<rev>.<ext>` (0700/0600),
   temp write + rename, row commit, then old file removed; recovery of a stray temp/old file at start. Deleting an
   agent removes its folder. Rev: random base64url. GET checks the agent exists and the rev is current (else 404),
   reads with no symlink anywhere on the path (see `ThemeStore.safeAssetPath` for the pattern).
4. Tests: migration (old rows keep style, new shapes accepted, bad look refused), every route incl. each rejection,
   symlink refusal, stale rev 404, agent delete cleanup, `agent.updated` emitted.

## 10.2b — web
1. `agent-shapes.ts`: geometry for the 12 new shapes in the 20-unit box, each a distinct silhouette at 18px (test
   that like the existing shape tests). Eye positions for every shape.
2. `AgentGlyph` renders by `style.look` / `style.avatar`:
   - **bot** (default): borderless body in the agent colour, two eyes (ink on light colours, white on dark — relative
     luminance threshold as in the preview), a soft shadow, thought dots. The lead's `circle-dot` becomes a solid
     round head (no other shape is round).
   - **chibi**: the preview's chibi (hair/outfit in the agent colour, shape as a white hair clip with a darker edge);
     enlarge the clip so shapes are distinguishable at chat size (~28px), or add a coloured shape badge there.
   - **picture**: the image (`/api/agents/:id/avatar?rev=`), object-fit contain, with a small badge (agent colour +
     shape) at the bottom-right; same motion as the bot.
   - **xs/list size**: always the plain coloured shape (no face, no picture), so lists stay readable.
   - Keep `aria-label`/`describeShape` behaviour, `bare`, `contrast='high'` and the glyph plate (I1) working.
3. **Motion follows state:** an optional `activity` prop (`idle | working | thinking | needs`) mapped from the agent's
   status where a live status is known (Team cards and agent page, Now lanes/Score, Chat roster and active agents,
   Flow nodes); elsewhere the glyph rests. Resting = breathe + occasional blink; working = squash bounce + glance;
   thinking = rock + look up + thought dots; needs you = hop + wide eyes + dots beat. `prefers-reduced-motion` →
   completely still. Hover: eyes follow the pointer (bot/chibi); no other interaction changes state.
4. **Choosing a look:** the agent page (Hermes and coding) and the Add/Import agent dialogs get a Look choice (Bot /
   Chibi), a much bigger shape picker (20 shapes, keyboard-navigable radio group) and, on the agent page, "Use a
   picture…" (file input, preview, Remove picture) calling the 10.2a routes; show the server's rejection reasons.
5. **Theme protection:** agent glyphs are protected surfaces; the guard's glyph signature / non-text contrast checks
   and `protected.css` plate rules must still hold for every look (update `protected-surfaces`, guard and tests; the
   themes e2e must pass). Default Score look otherwise unchanged except the glyphs themselves.
6. Tests: unit (shape distinctness, eye colour, look selection, reduced motion, picture badge), e2e (switch look,
   pick a new shape, upload a picture — use a generated neutral test PNG, never persona art — and remove it), visual
   baselines regenerated deliberately (every glyph changes): list them and check a sample of each surface.
7. Docs: USER-GUIDE (agent looks and pictures), README screenshots that show agents (`pnpm screenshots`, neutral
   team).

### 10.2c (pet corners), new
- `PetCorner` component (Team cards and the agent page header): the agent's glyph (any look) lives in a bounded
  corner with a floor and behaves per decision 106, using the preview's engine as the reference (`#pets` section and
  its script): an act scheduler per pet, walking with a left transition and flip, acts as classes on the pet, base mood
  from the agent's live activity, greet on pointer enter (stop, face, "hi!", eyes follow), hop + heart on click, sleep
  after ~25 s without attention (wakes on hover/click/state change). It never leaves its corner and never covers
  anything outside it; it is decorative (`aria-hidden` on the motion, with the agent's name and state as text for
  assistive tech), and it never takes focus or keyboard input except as a button that opens the agent where it
  already did.
- **Liveliness** per device (Settings › Look, "Agents: Lively / Calm / Still", stored like the colour mode): Calm = no
  walking or tricks, only breathing, blinking, moods and the greeting; Still = no motion; `prefers-reduced-motion` =
  Still. Timers pause when the tab is hidden; at most one animation frame budget per pet (CSS-driven, no per-frame JS).
- Theme protection: pet corners are part of the agent's protected surfaces; the guard and plate rules must hold.
- Works in the chat-first view where agents appear, at phone width (corners shrink, Calm by default below 600px).
