## Part 2 — endpoints nobody calls (report; the lead decides and edits the contract)

orchestration queries build `…/pause` from a base path), so it is only a starting list. For **every** route marked
`NONE` or `e2e` only, read the web app's query/action code (`apps/web/src/**/*-queries.ts`, `*-api.ts`, `data/`,
components calling `apiFetch`) and the plugin, and decide: **called** (where, file:line) or **not called** (evidence).
Also check endpoints the retired pages (BoldRuns, OrchestrationLive, the run frame) were the only callers of — `git show
v3.29.0:apps/web/src/bold/BoldRuns.tsx` and `git show v3.29.0:apps/web/src/routes/orchestrations/OrchestrationLive.tsx`
for what they called. Don't delete endpoints yourself.
