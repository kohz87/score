## Task (from docs/PLAN.md)

**4.2 Diff builder**: unified diff from patch/write tool args (pure). Done when table tests pass.

## Design (from the lead)

- `apps/server/src/domain/watch-diff.ts`: `editorFrameFromTool(tool: string, args: unknown, result: unknown, previous?:
string | null) → { path: string; diff: string; language: string | null } | null`. Hermes 0.21.5 file tools (verify the
  exact argument shapes in `../reference/hermes-agent/tools/`): `write_file` (path + content: a diff against `previous` when
  known, else an all-added diff), `patch` (Hermes's patch formats: unified diff text and/or find/replace style — normalise
  to a unified diff for that path; multi-file patches → one frame per file, return an array instead if needed and say so).
  `read_file` and others → null. Language from the file extension (small table). Validate with zod; never throw on
  malformed input (return null). Caps: diff ≤ 64 KB UTF-8 (truncate whole hunks, add "… N more lines" marker).
- Reuse `apps/server/src/domain/line-diff.ts` (already in the repo) for computing line diffs.
- No I/O, no Hermes imports beyond types; redaction is the caller's job (4.1).
