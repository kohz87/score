## Design (from the lead; exact values from `docs/design/html/`)

A glyph is a **tinted rounded tile** with a **shape** in the agent's color, centred. From the mocks:

| Size | Tile | Radius | SVG (viewBox 0 0 20 20) | Used in              |
| ---- | ---- | ------ | ----------------------- | -------------------- |
| `sm` | 34px | 11px   | 18px                    | chat messages, chips |
| `md` | 40px | 13px   | 20px                    | team sidebar         |
| `lg` | 44px | 14px   | 24px                    | Score lanes          |

Add an `xs` size for inline text (20px tile, radius 7px, 12px SVG) and a `bare` prop that renders only the
shape (no tile) for legends and chips.

The four shapes in the design (copy these paths exactly; `C` = agent color):

- `circle-dot`: `<circle cx="10" cy="10" r="6.5" stroke="C" stroke-width="2.4"/><circle cx="10" cy="10" r="2.4" fill="C"/>`
- `triangle`: `<path d="M10 3 L17.5 16 H2.5 Z" fill="C"/>`
- `diamond`: `<path d="M10 2.5 L17.5 10 L10 17.5 L2.5 10 Z" fill="C"/>`
- `square`: `<rect x="4" y="4" width="12" height="12" rx="4" fill="C"/>`

Design the other four in the same visual language (filled, about 13–15 units across, optically centred, distinct
silhouettes even at 12px): `hexagon`, `star` (5 points), `pill` (horizontal capsule), `cross` (plus sign with
rounded ends). They must be distinguishable from each other and from the four above **by silhouette alone**.

**Tint**: the tile background is the agent tint. For the four palette colors use the design tints exactly
(`#6B4EFF`→`#ECE8FF`, `#19C39A`→`#DDF6EE`, `#FFB61E`→`#FFF1D1`, `#FF6B8A`→`#FFE3E9`). For any other color compute
a tint by mixing it with white at 15% color / 85% white (sRGB). Export the helper `agentTint(color)`.

**Accessibility**

- Props: `agent: { id: string; name: string; style: AgentStyle }` (from `@score/contract`), `size`, `bare?`,
  `decorative?`. When not decorative: `role="img"` and `aria-label="<name>"` (plus ", <shape>" only if
  `describeShape` is true). When decorative: `aria-hidden="true"` (used when the name is printed right next to it).
- **High contrast**: `contrast="high"` prop, also applied automatically under `@media (prefers-contrast: more)` via
  CSS. The shape gets a stroke of the agent color darkened by mixing 45% with ink `#12131A`, and the tile gets a
  1.5px ink border. In high contrast, the shape must reach a **3:1** luminance contrast ratio against the tile
  (WCAG non-text contrast). Default mode keeps design fidelity.
- Never rely on color alone: shape silhouettes differ (above).

**Files**: `apps/web/src/components/AgentGlyph.tsx`, `apps/web/src/components/agent-glyph.css`,
`apps/web/src/components/agent-shapes.ts` (shape → SVG element data), tests next to them. CSS classes and
custom properties, no inline style objects except the per-agent CSS variables (`--glyph-color`, `--glyph-tint`).

## Done when
