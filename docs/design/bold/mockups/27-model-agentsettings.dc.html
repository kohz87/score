WHO WINS
A chat's own model wins in that chat; everywhere else the agent's model applies. /model no longer changes the agent everywhere: that's the Change button here.
The list is the same one Change shows: the agent's aliases, then the models its providers offer. A coding agent lists its CLI's models (sonnet, opus…).
If the chat's effort doesn't fit the new model, the chat goes back to the agent's own effort and says so. Fallback models still apply if the chosen one is unavailable.
