WHO WINS IN A JOB
A step's model wins for that step. A step left on "its own" uses the job chat's /model if one is set, else the agent's.
The same list as /model: aliases, then the models the agent's providers offer; for a coding agent, its programs' models.
Starting a job shows the steps with their models, so a costly one (max, opus) is seen before it runs.
A recipe can repeat on a schedule: each run is one job, builder drafts, reviewer checks, each on its step's model. That is the multi-agent repeating job; an agent's own repeating job is one agent, one prompt.
