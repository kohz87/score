- **P1 — Previous #3: semantic loss still permits a successful Codex result.**  
  [codex.ts:52](apps/server/src/runtimes/coding/codex.ts:52), [line 117](apps/server/src/runtimes/coding/codex.ts:117), [service.ts:1081](apps/server/src/runtimes/coding/service.ts:1081).

  **Fix:** make relevant semantic loss sticky for the entire attempt, validate every message phase, and finalize eligibility after complete stdout processing.

- **P1 — Previous #5: a barrier raised after admission does not prevent fallback execution.**  
  [service.ts:986](apps/server/src/runtimes/coding/service.ts:986), [line 1198](apps/server/src/runtimes/coding/service.ts:1198).  
  A queued turn is admitted, then an orphan/journal barrier rises while it waits. `fallbackAuthorised()` checks shutdown and held groups, but never `unit.block()`. The probe successfully journaled `releasing` while the blocker returned a refusal. The startup blocker also filters out general journal/restore items at [start-server.ts:388](apps/server/src/start-server.ts:388).  
  **Fix:** use one admission barrier for both backends and recheck it inside fallback release, including journal-history and restore uncertainty.

- **P1 — Previous #6: restored fallback survivors can remain running without an effective hold.**  
  [service.ts:1300](apps/server/src/runtimes/coding/service.ts:1300), [line 1317](apps/server/src/runtimes/coding/service.ts:1317), [line 1377](apps/server/src/runtimes/coding/service.ts:1377).

  **Fix:** retain routing and survivor identities externally, reconstruct an effective hold when the run row is missing, and fence identity-less release uncertainty. Project fallback phases/backend/checkpoint in the same critical sections; currently fallback transitions pass no projection.

- **P1 — Previous #10: copying a snapshot of source evidence is insufficient to retire inherited work.**  
  [installation.ts:429](apps/server/src/installation.ts:429), [line 442](apps/server/src/installation.ts:442), [line 570](apps/server/src/installation.ts:570).

Separately, the source lock ends after reading: the source can dispatch an inherited pending intent afterward, while the confirmed copy later dispatches its own copy. Lifting the copy fence does not permanently retire that unwitnessed inherited intent.  
  **Fix:** durably retire inherited execution intents before publishing an admissible copy identity; reject missing post-cutover source evidence. Treat inherited execution identities as evidence of past work, without granting ownership of its processes.

- **P1 — Previous #11: a later number substitutes for a missing cutover witness.**

Additional findings follow. The first two are direct regressions in the fix round.

1. **P1 — Cleanup can discard unread stdout and certify a complete stream.**  
   [supervisor.mjs:433](apps/server/src/runtimes/coding/supervisor.mjs:433), [line 334](apps/server/src/runtimes/coding/supervisor.mjs:334).  
   When the payload is empty but output is paused under backpressure, the new cleanup loop destroys the pipes after one grace. Their `close` handlers emit ordinary EOF with the last *transmitted* sequence, without marking loss. The probe discarded an unread `turn.failed` record after a successful candidate, then emitted clean EOF/end and exited 0.  
   **Fix:** keep payload cleanup independent of pipe draining, but distinguish actual EOF from forced closure. Forced closure or read failure must make the stream lossy and the result ineligible.

2. **P1 — Confirmed-copy recovery stops the source installation’s units.**  
   [installation.ts:463](apps/server/src/installation.ts:463), [unit-backend.ts:1157](apps/server/src/runtimes/coding/unit-backend.ts:1157), [line 794](apps/server/src/runtimes/coding/unit-backend.ts:794).  
   Source records are rewritten into the copy’s scope while preserving unit names and InvocationIDs. Recovery treats every record containing `unit` as owned; stopping checks name syntax but not this installation’s prefix. The probe’s installation `22222222…` issued `stop` for a `score-11111111-c-…` source unit.  
   **Fix:** distinguish inherited witnesses from owned launches, retire inherited process projections during copy confirmation, and enforce installation-prefix ownership at every stop/reset boundary.

3. **P1 — Eligibility notes write recognized secrets directly to SQLite.**  
   [unit-backend.ts:962](apps/server/src/runtimes/coding/unit-backend.ts:962), [antigravity.ts:208](apps/server/src/runtimes/coding/antigravity.ts:208).  
   Driver refusal text includes CLI-supplied denied-action names or status. `noteEligibility()` stores it after slicing, without redaction. The probe stored `password=review-sentinel` verbatim in `coding_launches.eligibility`.  
   **Fix:** apply `redactBounded` before persistence, or store controlled reason codes and separately redacted explanatory text.

4. **P1 — Stderr truncation removes the label needed to redact a secret.**  
   [unit-backend.ts:591](apps/server/src/runtimes/coding/unit-backend.ts:591), [coding-socket.ts:350](apps/server/src/runtimes/coding/coding-socket.ts:350), [service.ts:169](apps/server/src/runtimes/coding/service.ts:169).  
   Raw diagnostics are bounded before redaction. `password=` followed by a 10,000-character value becomes an unlabeled 8 KiB tail; later redaction leaves that value in the failure notice. The probe confirmed that whole-input redaction masks it while the retained tail survives unchanged.  
   **Fix:** use bounded streaming redaction that preserves secret-value state across chunks. On diagnostic overflow, discard unsafe raw text rather than retaining an unlabeled secret tail.

5. **P1 — Name-based stopping still has an identity check-to-action race.**  
   [units.ts:367](apps/server/src/runtimes/coding/units.ts:367), [line 371](apps/server/src/runtimes/coding/units.ts:371).  
   Invocation A passes the check; before the name-based stop executes, another invocation occupies the name. Score stops that foreign invocation and only afterward reports `uncertain`. The boundary probe reproduced this sequence.  
   **Fix:** use the authenticated connection or a retained, identity-checked pidfd for the recorded supervisor. If ownership cannot remain pinned through the action, retain uncertainty instead of stopping by name.

6. **P1 — Ended proof can check a different cgroup from the recorded one.**  
   [unit-backend.ts:853](apps/server/src/runtimes/coding/unit-backend.ts:853), [line 860](apps/server/src/runtimes/coding/unit-backend.ts:860).  
   With matching InvocationID but conflicting cgroup metadata, proof prefers the current `ControlGroup` over the journaled cgroup. The probe returned `proven: true` for an empty current cgroup while the recorded cgroup was populated. Manager identity is not rechecked on this path, and rebuilding a launch loses its DB-only manager/boot record.  
   **Fix:** prove the recorded cgroup, reject identity/cgroup disagreement, retain manager and boot identity externally, and recheck incarnation before every proof and stop.

7. **P2 — An early `end` can acknowledge output before ingestion finishes.**  
   [coding-socket.ts:422](apps/server/src/runtimes/coding/coding-socket.ts:422), [line 430](apps/server/src/runtimes/coding/coding-socket.ts:430), [line 451](apps/server/src/runtimes/coding/coding-socket.ts:451).  
   `end` is accepted before EOF/exit, acknowledged immediately, and followed by additional output. The probe closed with a handler still pending and returned `eligible: true`; that handler then failed.  
   **Fix:** enforce terminal ordering, reject output after `end`, require both EOFs and exit before ACK, and disqualify closure with queued or in-flight ingestion.

8. **P2 — Fallback waivers are forgotten by the new external recovery path.**  
   [service.ts:1504](apps/server/src/runtimes/coding/service.ts:1504), [line 1293](apps/server/src/runtimes/coding/service.ts:1293).  
   Human Release deletes process rows and records an in-home audit, but leaves the external launch unsettled. Restart recovery consequently reconstructs the waived identity and attempts to stop it again. The probe reproduced an additional stop attempt after Release.  
   **Fix:** journal waiver/disposition before deleting projections, settle the waived launch, and make recovery honor that permanent decision.
