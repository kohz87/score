## Raw report — Codex

Reviewed `v1.8.0` without changing files. Verification used source tracing, in-memory Fastify/SQLite probes, a virtual filesystem and jsdom. Chromium and `pnpm check` were not run.

1. **A1 — P1: Asset reads follow symlinked directories outside Score.**  
   [store.ts:188](/home/raven/score-worktrees/xaudit/apps/server/src/themes/store.ts:188), [themes.ts:274](/home/raven/score-worktrees/xaudit/apps/server/src/http/themes.ts:274).  
   If `themes/audit/assets/img` is a symlink to another directory, export follows it and includes its regular files—even filenames the package importer forbids. The probe exported an outside `secret.txt`. Checking only the final file with `lstat` does not secure its parents.  
   **Fix:** reject symlinks throughout the path, use verified directory/file handles, and make export use the same safe asset reader.

2. **A2 — P1: Approval-policy and permission controls remain outside protection.**  
   [NewOrchestrationDialog.tsx:242](/home/raven/score-worktrees/xaudit/apps/web/src/routes/orchestrations/NewOrchestrationDialog.tsx:242), [McpAccessSection.tsx:22](/home/raven/score-worktrees/xaudit/apps/web/src/routes/team/McpAccessSection.tsx:22).  
   Both filters accept `.orch-policy { opacity:0 }`, hiding the approval-policy choices. “Start orchestration” has neither a protected ancestor nor a decision boundary; its decision check returns `null`. MCP read/write permission controls similarly lack protection.  
   **Fix:** protect complete consent surfaces and their submission boundaries. Test actual forms with hidden policy/context fields; the protected-class inventory test cannot detect these omissions.

3. **A3 — P1: The Customizer import dialog can overwrite a concurrent save.**  
   [ImportDialog.tsx:113](/home/raven/score-worktrees/xaudit/apps/web/src/routes/customizer/ImportDialog.tsx:113).  
   A reviews an import and selects Replace; B saves that theme; A clicks Install. This call sends `replace=1` without `If-Match`, and the server overwrites B’s version with `201`. This contradicts the documented conditional replacement guarantee.  
   **Fix:** capture the installed theme’s etag when presenting replacement consent and send it on installation; require renewed review after a conflict.

4. **A4 — P1: Successful replacements still produce mixed-version previews and copies.**  
   [themes.ts:153](/home/raven/score-worktrees/xaudit/apps/server/src/http/themes.ts:153), [save.ts:35](/home/raven/score-worktrees/xaudit/apps/web/src/themes/customizer/save.ts:35).  
   Read manifest/CSS/etag A, then replace the same asset path with B. A’s asset URL returns B’s bytes—even with A’s `If-Match` supplied. “Save as new” can therefore store A’s metadata with B’s assets and licences. The release notes acknowledge this limitation.  
   **Fix:** enforce revision-bound asset/licence reads or load and retain one complete package snapshot for preview, copying and export.

5. **A5 — P1: Swap recovery lacks host-crash durability.**  
   [store.ts:341](/home/raven/score-worktrees/xaudit/apps/server/src/themes/store.ts:341), [store.ts:363](/home/raven/score-worktrees/xaudit/apps/server/src/themes/store.ts:363), [database.ts:57](/home/raven/score-worktrees/xaudit/apps/server/src/db/database.ts:57).  
   Files and directories are never synced, while SQLite uses `synchronous=NORMAL`. After replacement and old-folder cleanup, power loss can preserve filesystem changes while losing the journal and new row, leaving old metadata with new assets and no recovery note. This finding follows from persistence ordering; exception-injection tests do not exercise it.  
   **Fix:** durably commit the journal before moves, sync staged files and directory changes, and durably commit the replacement before deleting the old folder.

6. **A6 — P1: Refreshing coding-agent settings silently destroys personality drafts.**  
   [CodingAgent.tsx:396](/home/raven/score-worktrees/xaudit/apps/web/src/routes/team/CodingAgent.tsx:396).  
   A edits personality while B saves newer instructions. When A refreshes the coding-agent query—for example by saving another settings card—the changed key unmounts A’s editor. The probe lost the draft and showed B’s text without offering the documented conflict choices.  
   **Fix:** key the editor by agent identity, preserve its draft/base etag while editing, and surface incoming changes as conflicts.

7. **A7 — P1: A theme can hide the Customizer’s way back; its palette is absent.**  
   [Customizer.tsx:566](/home/raven/score-worktrees/xaudit/apps/web/src/routes/customizer/Customizer.tsx:566), [App.tsx:54](/home/raven/score-worktrees/xaudit/apps/web/src/App.tsx:54).  
   Both filters accept `.cz-back { opacity:0; color:transparent }`. That Settings link is unprotected, and the full-screen route mounts neither shell that supplies the command palette. Consequently the link disappears without triggering protection, and Ctrl/Cmd+K offers no reset there.  
   **Fix:** protect the link and mount emergency navigation/reset commands independently of page shells.

8. **A8 — P1: Failed Git checks are reported as clean history.**  
   [git.ts:140](/home/raven/score-worktrees/xaudit/apps/server/src/knowledge/git.ts:140), [vault.ts:1078](/home/raven/score-worktrees/xaudit/apps/server/src/knowledge/vault.ts:1078).  
   If Git stops working after initialization—for example, its index becomes corrupt—`pathDirty()` catches the failure and returns `false`. An uncommitted note then reads as `{versioned:true, history:"unchanged"}`, removing the history-failure warning/retry. The injected Git-error probe confirmed this result.  
   **Fix:** distinguish clean from unknown/error and retain `failed` or `git_unavailable` until history can be verified.

9. **A9 — P2: A failed quota refresh can still block new work.**  
   [service.ts:400](/home/raven/score-worktrees/xaudit/apps/server/src/runtimes/coding/service.ts:400).  
   Cache an Antigravity reading with 4% left. At 61 seconds, let refresh fail. The guard still receives that reading until 120 seconds and holds work below the 10% floor, despite the contract saying failed reads never block.  
   **Fix:** invalidate the guard’s trusted reading when refresh fails; keep historical display data separately if needed.

10. **A10 — P2: “Save as new” retains the old name and becomes spuriously dirty.**  
    [draft.ts:532](/home/raven/score-worktrees/xaudit/apps/web/src/themes/customizer/draft.ts:532).  
    Save an unchanged “Old” theme as “New”. Because `submitted` already contains the new name/id, comparison with the original draft falsely detects concurrent edits. The resulting draft is `{id:"new", name:"Old"}`, its baseline says “New”, and it remains dirty. Another Save renames the copy back.  
    **Fix:** compare against the draft captured before save-time transformations, then adopt persisted fields unless those fields were edited during the request.

11. **A11 — P2: The actual ZIP inflaters still disagree.**  
    [package.ts:67](/home/raven/score-worktrees/xaudit/apps/server/src/themes/package.ts:67), [zip.ts:108](/home/raven/score-worktrees/xaudit/apps/web/src/themes/customizer/zip.ts:108).  
    Put valid deflated `theme.json` data followed by bytes `00 01 02` inside its declared compressed extent, with matching headers and correct uncompressed size/CRC. The server accepts the package; the browser reader rejects it. All existing 59 corpus cases pass, so they do not prove inflater agreement.  
    **Fix:** enforce complete compressed-input consumption server-side and add deflated trailing-data cases to the shared corpus.

12. **A12 — P3: `constructor` is incorrectly treated as a built-in theme.**  
    [builtin.ts:63](/home/raven/score-worktrees/xaudit/apps/server/src/themes/builtin.ts:63).  
    A valid new theme with `id:"constructor"` receives `409 builtin_theme`: `PACK_NAMES[id]` reads inherited `Object.prototype.constructor`.  
    **Fix:** use a `Map`, a null-prototype object, or an own-property check.

The shared 59-case package corpus agrees through both actual readers.  
Injected swap failures restored the previous package; unsettled package reads returned `409 theme_recovering` and recovered afterward.  
Watch correctly separated identical captions by parent call ID in the probe.  
The lockfile/licence exceptions are unchanged, and the new bundled fonts carry OFL files and notices.
