# 3.x whole-app review (lead, 2026-10-26)

Codex was not available (owner: in use on another project), so the lead did this review itself (CLAUDE.md fallback).
Scope: everything between v2.8.0 and v3.1.0 — the classic-shell removal (3.0.0), the e2e port and its product fixes,
and 3.1.0. Server, Hermes plugin and contract are unchanged in that range (only version numbers).

## Method
- Diff by area (`git diff --stat v2.8.0 v3.1.0`), reading every new/changed non-test file in the web app; the deleted
  files checked against what the new shell still imports.
- Each release's own Sonnet reviews and fix rounds (TASKLOG) taken as input, not repeated.
- Focus: anything that can send the person elsewhere, hide or fake a decision, lose data, or leave code unreachable.

## Findings
- **Redirects** (`shell/framed-paths.tsx` `classicRedirectFor`, `App.tsx` loaders): every target is a same-origin
  `/b…` path; query and hash kept; malformed escapes don't throw (`decoded`); no loops. No open redirect.
- **Notifications** (`NotificationBridge`, now mounted in the new shell): click targets pass `isAppPath` (a `/` path,
  not `//`) and go through the router; service-worker messages are checked the same way. Safe.
- **Protected surfaces**: `styles/protected.css`, `themes/guard.ts`, `themes/protected-surfaces.ts` unchanged in 3.x
  except dropping `.update-banner` from KNOWN_OVERLAYS (it is no longer fixed). Glass (`bold/bold-shape.css`) skips any
  card holding a protected surface except an agent glyph (identity on its own fill); a unit test pins that the glyph
  is the only exemption, and e2e proves a decision under glass stays opaque with the guard quiet.
- **Orphans**: no unreferenced source files remain (motion/anime, the Customizer and the test setup files are loaded
  dynamically or by config).
- **Product bugs found during 3.x and fixed** (see TASKLOG): Settings gear unprotected; unchecked-build notice only in
  Settings; Harbour switched off by the guard (gear aria-current); shared-message source line on a picture; Start a job
  offering non-ready agents; /compress in a one-to-one; the room not following its end, then following too eagerly
  (hover rows, shrinking streams); notifications and the update banner never mounted in the new shell; open terminals
  not listable; the phone roster strip overflowing.

## Residual risks (not blocking)
- e2e: `bold-workspace.spec.ts:129` 1px screenshot height difference seen once under full load, not reproduced.
- The test suite shares one fake server across ~820 tests; specs that read team-wide state still need the roster/look
  locks — new specs must use them (`holdLockPerTest`).
- Glass uses `backdrop-filter` on many cards; fine on the target browsers, worth watching on low-end phones.

No P1/P2 open after this review.
