## Checked premises

- `task_events` and `task_runs` are `INTEGER PRIMARY KEY AUTOINCREMENT` in both the current schema and
  `kanban_db_connect.py`'s rebuilt shape, so `sqlite_sequence` rows exist once a row was ever inserted (v5 §A holds).
- Hermes's legacy-shape migration (`kanban_db_connect.py`, TEXT ids → AUTOINCREMENT) reassigns ids and resets cursors.
  Under v5 that lowers the allocation marks → contradiction → new history, which is the right outcome. Needs a fixture.
- Legacy activity items (`task-model.ts` `eventActivity`) keep only `at` (seconds), `agentId` (payload author/profile)
  and `text`; no event id, attempt id or event kind when a payload has text.

## Findings

1. **[medium] §E's affirmative proof is mostly unsatisfiable, and the design should say so.** Case (1) "claim event id"
   is never stored; "start timestamp equal" matches any activity in that second. Case (2) needs a profile that claim
   payloads usually lack. Expected outcome: nearly all legacy numeric links become `unresolved`. That is safe, but the
   UI must handle it well. **v5.1:** the only allowed proof is an activity item whose text is the claim kind
   ("claimed"), whose `at` equals the attempt's frozen `started_at` second, and whose `agentId` equals the frozen claim
   profile. Everything else is unresolved. Unresolved links render as "an earlier attempt (details not kept)".
2. **[medium] Watermarks and page rows must come from one read transaction.** If the marks are read outside the page's
   snapshot, a concurrent Hermes write can make a page look inconsistent with its saved marks. **v5.1:** every capture is
   one `BEGIN … COMMIT` read transaction on the read-only connection covering `sqlite_sequence`, the min/max probes and
   the page rows.
3. **[medium] `kanban_pages` grows without bound.** **v5.1:** keep page rows 7 days (they are retry identities only);
   pruning runs in the hourly retention pass and never removes the latest page of an open capture.
4. **[low] `task_snapshot` is user text.** **v5.1:** redacted through `redactBounded`, title ≤ 300 chars, JSON ≤ 4 KB.
5. **[low] Now `checks[].ok` → `verdict` is a contract break.** **v5.1:** checks are computed on read today (no stored
   form), so the change is contract + web only. Old clients aren't supported (single deployment); record it in the
   contract changelog.
6. **[low] Paused sources hold pauses.** When a source is paused, team/agent pause release must not stay stuck on
   inert holds. **v5.1:** release skips inert holds and reports them in the result ("2 tasks are on an unverified board
   and stay as they are").
7. **[fixture] Add:** the Hermes legacy-shape migration (ids reassigned → new history); a capture whose rows changed
   between two of its queries (proves the single read transaction).
